# 0.2.0 材料识别、阅读与分类

本规则适用于本插件的整理与手写识别 Skills；与旧文档“所有内容全文保留”“默认进入课程”的措辞冲突时，以本文件的分类和唯一精简例外为准。只有用户要求整理/归档/补齐才写入；仅上传附件、提问或更新插件不写入。

## 先识别来源，再识别内容

逐个登记图片、PDF、聊天及混合材料：原文件名、SHA-256、页数、可读页范围、原始来源、已提取/待识别/不确定状态。使用实际可用的视觉或 PDF 阅读能力。文字 PDF 提取文字后检查页面中的公式、图表及阅读顺序；扫描 PDF 逐页视觉识别/OCR，不能把提取不到文字说成空白页。长文件分批并维护页覆盖清单，不只读开头。图片保留图片编号及区域，PDF 保留页码；模糊公式、符号、数值标待核实，不猜测。无访问能力时指出具体文件/页段；无法确定页数时明确未知。

`scripts/inspect_material.py` 可生成原件哈希及 PDF 逐页文字清单（可选 pypdf）；它不是 OCR 工具，返回 needs_visual_review 或 extractor_unavailable 必须继续视觉读取或报告阻塞。仅凭扩展名、文件标题或该脚本不能判定内容主题。

## 三种归档类型

|类型|识别依据|详细程度|Notion|GitHub|
|---|---|---|---|---|
|课堂 course|当前学期课程身份、用户说明、课件/课堂/作业上下文，并匹配真实课程|全部可读原始问答、推导、解释、计算，不精简|沿用已配置课程库 → 课程 → 日期/专题|沿用 `课程/<课程名>/`|
|知识 knowledge|课外专题、技能、一般知识，且已排除当前课堂|保留完整知识和可读问答，不精简|私人学习资料库 → 知识 → 领域|`知识/<领域>/`|
|读书 reading|书名/书籍上下文、章节或阅读笔记|原读书笔记不精简；仅阅读聊天可凝练重复口语，保留观点、论据、问题、思考、结论|私人学习资料库 → 读书笔记 → 主题 → 书籍|`读书笔记/<主题>/<书名>/`|

课堂专属于本学期，机械主题或匹配课程关键词不足以判为课堂。过往学期/不明确材料先说明或询问，不擅自放入本学期课程。读书聊天与同一本书的笔记放一起，不另建顶层“聊天”类别。书名、作者、版本不明则标未知；影响去重/书籍归属时询问，不能虚构作者或书名。同名不同书通过已知作者/版本区分。混合材料按实际内容拆分笔记，共用原件，跨类建立真实链接。

读取现有分类及内容后决定复用或新增。不相关的新主题在对应大类下建子分类；明确课外的旧 `领域/` 可以沿用，不能借此写入 `课程/`。课程无匹配与查询失败不同；失败不能当新类别。分类不明时继续处理已确认部分，询问必要信息，未确认部分不写入错误位置。

## Notion 资料库与原件

保留现有课程配置。首次真正归档课外材料时，查找用户已确认的私人“学习资料库”，复用真实页面 ID；不存在则创建私人根页，再创建“知识”“读书笔记”子页。不能在共享空间随意建库；当前连接无法创建私人根页时，请用户指定私人父页面，保留待上传草稿。以后使用实际读取/返回的页面 ID，不编造持久配置。

图片与 PDF 原件均默认保存到 Notion 和已配置的 GitHub 私有仓库。先按原件 SHA-256 对比各目标已验证记录，再上传缺失目标。Notion 使用当前文件上传工具的真实 upload 凭证；`upload_notion_image.py` 支持图片与 PDF 单段上传，PDF 按 file/pdf 附件挂载，不能当 image 块。上传完成后还要附到笔记中并回读附件；上传未挂载不算归档完成。以当时 API 限制为准，助手上限不等于账户配额。超过限制保留本地原件并报告，未经授权不改用公开托管。

GitHub 可用 `archive_github_assets.py`，将原始字节保存至 `_assets/<sha256>/original.<格式>`；保留原文件名、来源及页码在笔记 YAML/来源清单中。同字节改名只保存一次，混合类别共用附件。脚本仅支持不超过 900000 字节的原件，超限明确报告，使用可用的已授权大文件工具时仍需按提交回读校验；不把缩略图当原件。不要将私库 raw 链接当 Notion 已上传原件。

## 内容、补充与回执

YAML 保留既有字段、公式及 related_candidates，新增 `content_type: course|knowledge|reading`、`detail_mode: full|reading_dialogue_condensed`；阅读聊天才可用后者。来源清单注明源文件、哈希、页码/图片区域、读取覆盖、不确定项、原件两端链接。

原文全文标准继续用于课堂和知识；阅读聊天明确标“阅读对话整理（已精简）”，不能声称逐字保留。补传时与两端现有原文/观点/推导/媒体分别比较，仅补新增和缺失部分。已有完整相同内容不再保存，不改日期、不生成空报告、不产生空提交。阅读摘要中遗漏的重要观点仍属新增，不能因摘要相似跳过。附件重复不代表其新解释也重复；分别检查。

按目标逐项报告：来源读取覆盖、分类依据、精简模式、新增笔记路径、重复跳过、原件上传与挂载状态、真实 commit、回读验证和未完成项。能力不可用、OCR不确定、原件无法访问都如实说明；不能把说明文档或单元测试当真实手机/PDF/Notion端到端实测。


## 手写材料入口（0.2.3）

发现手写文字、公式或补注时执行 [手写识别与校对](../../handwritten-notes-ocr/SKILL.md)，按原图/页码和区域保留完整转写、图中标注及待确认项。先识别复核再分类整理，不确定内容不能由知识推断替代。只识别不自动归档；原件及已有目标规则继续适用。
