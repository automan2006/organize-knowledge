# Notion 课程学术笔记

先核实使用者已连接自己的 Notion，并已指定归档位置。明确调用并要求保存即授权在该位置创建本次笔记与图片；只预览时不写入。首次使用没有指定位置时先询问，不自行选择搜索到的课程库。独立使用时先按 [知识提取规则](../study-chat-notes/references/extraction.md) 建立覆盖清单。

## 课程与归档

读取 [课程位置配置](references/course-config.md) 和 [长文字模板](references/academic-template.md)。有题目、计算或推导时必须读取 [手机公式与分步计算](references/formula-presentation.md)，根据公式宽度选择字号，长式缩小、必要时拆行；计算结果之后的判断与最终取值另起块。用原生数学块和彩色框突出重点，不能一律放大，也不能把全部计算挤成普通正文。本插件依赖现有 Notion 连接，不自建持有 Notion 凭据的服务。

1. 先检查 Notion 工具权限；根据当前 access map 使用可用搜索工具。AI search 不可用时用普通 search，避免使用套餐限制字段。读取 `notion://docs/enhanced-markdown-spec`（通过 Notion fetch 或其资源接口），遵守当前工具 schema，不假设参数。
2. Fetch 配置的课程库/数据源，按真实 schema 查询课程并核实目标页面。多候选或找不到匹配时仅询问课程归属；不擅自建立课程或改数据库 schema。
3. 默认在匹配课程页面下创建“YYYY-MM-DD｜主题｜聊天知识笔记”子页。一个聊天跨课程则为各课程建立对应笔记；很长时用总览子页加专题子页。复用课程体系，不将聊天整理冒充实际“上课记录”。
4. 写入前搜索本插件同来源同主题记录，读取内容与整理标识。已有完整同内容则返回原页；有新内容则在该插件笔记中定点追加/修订，保留人工添加段落。不能可靠识别原笔记时询问，避免靠日期或相似标题覆盖用户内容。无需修改课程页正文即可通过创建子页建立归属。
5. **图片属于必须执行的归档步骤**：先阅读 [图片上传、插入与验证流程](references/images.md)，处理用户发的全部图片，以及助手回答中的生成/绘制示意图、实物配图和检索图片网格/卡片。能取得原文件时必须实际上传，不能停在登记文件名。带 Python 的执行环境使用随包上传程序完成文件 POST；SVG 可直接通过附件工具上传。只有整屏截图时保存截图并注明独立原图缺失，不能按截图内格子数量充当原图上传数。手机/网页按实际文件能力选择路径，缺原文件或传输能力时明确列缺图，不能谎称成功。
6. 按课程笔记模板的三栏主体、底部两栏及原生配色保存正文，将已上传图片插入对应知识点后回读验证。核对两类实际图片块、分栏、颜色、目录、截断/未知块、课程父级，以及公式的宽度检查和合适字号、代入与结果的独立块、计算后的换段及结果框。任何缺图时报告“部分完成”。结果不确定先查状态，避免重复上传或重复建页；只重试已明确失败的缺失部分一次，仍失败则报告具体阶段与补传位置。

只写本次笔记和已识别的插件笔记；不删除、不搬移现有课程、数据库或人工笔记。引用现有页面用 mention/link，不能用可能移动页面的 `<page>` 或 `<database url>` 代替引用。

## 交付

返回真实页面链接、课程归属、覆盖范围，以及“用户图片 N/M；助手示意图 N/M”的独立完成数。只有上传完成、已插入且回读验证的图片计入已保存数；有缺图时首段标“部分完成”并列出具体补传办法。用户要求补图时读取原笔记并原位补入，保留已有全文。连接不可用时交付草稿并说明待连接，不谎称保存成功。
