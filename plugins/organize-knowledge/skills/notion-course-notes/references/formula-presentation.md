# 手机可读的公式与分步计算

优先级：手机完整显示 → 字号仍可读 → 重点醒目。保持可编辑的 Notion 原生 equation 块和彩色 callout，保留全部数学内容。禁止沿用旧版本“一律大号”的做法。

## 1. 按公式宽度选择字号

归档时检查的是排版宽度，不是 LaTeX 源码字符数；分数取分子/分母较宽者，上下标、单位、方框及公式所在容器也计入。以手机为默认阅读场景：callout 内按可用宽度约 220 CSS px 作保守检查，全宽正文约 260 px。它是默认预算，不是读取了用户 iPhone 的实际屏幕；用户有大字体或截图显示更窄时下调预算或增大基准字号。

- 短公式：只有在预算内有余量时才用 `\large`，以粉色背景和粗体“关键公式”标签保持醒目。
- 长公式：按 `\large` → `\normalsize` → `\small` 逐级选择能容纳的最大字号。长分数和多项相加优先常规字号，不默认 `\Large`。
- 仍超宽：先移除多余的外层 `\boxed`（保留颜色框），再按等号、推导步骤或独立计算结果拆成短公式块。不得删符号、单位、适用条件或用省略号代替。不要缩到 `\scriptsize`/`\tiny`。
- 两条结构相似的相邻公式（如总拉力和残余压紧力）采用较小的共同字号，避免一大一小。多个答案不要挤在一个超长方框里，分别成块或分行。
- 并列公式、条件、答案后面的中文判断不与长式同放一行。详细公式放主栏或全宽区，侧栏只放能完整显示的短式。

有 Python 环境时，使用随包的 [宽度估算程序](../scripts/fit_notion_equation.py)：

```text
python scripts/fit_notion_equation.py --input PRIVATE_EQUATION_TEXT_FILE --width-px 220 --base-font-px 16
```

输入为 UTF-8 文件，也可用 stdin；避免直接把含反斜杠和美元符号的 LaTeX 拼入 shell 命令。程序无需外部依赖，只调整字号，不修改数学表达式。`estimated_width_px` 是估算，`needs_split_or_review` 为 true 时必须人工拆分/检查，不能直接保存后声称已适配。未知命令或多行环境会明确要求复核。

有浏览器/KaTeX 渲染能力时以实际渲染的固有宽度复核；不能测量固定宽度容器本身来冒充公式宽度。缺执行能力时按上述保守规则选择常规或较小字号、分成短块，说明未实测；不得假称实时自动适配每个设备。Notion 保存的字号不会随屏幕实时切换，插件是在生成/更新笔记时选择字号。

## 2. 计算完成后另起段落

每小题固定为“条件 → 代入计算 → 计算结果 → 判断说明 → 最终取值”。每一步是独立块；计算结果后的说明必须另起自然段，不能写成“=583.8 MPa；按屈服条件……最终取550 MPa”的同一长段。

- 计算公式用独立 equation 块。长等式链拆开写，不在一个块里串三四个等号。
- 数值结果单独成块，单位仍保留。需要近似时使用近似号。
- “超过屈服上限”“按本题模型取值”等判断写成后续普通段落，利用原生块间距留白。
- 最终取值用绿色 callout 内短公式，字号同样经过宽度检查；不强制放大。
- 多个小题分三级标题或有内容的步骤块，避免一个编号项里挤满条件、长式、结果、解释。

## 3. 结构示例

以下是针对用户截图的排版示例，公式与数值仅用于本次验证，不套用到其他题目。嵌套内容用制表符缩进。

```text
<callout icon="∑" color="pink_bg">
	**关键公式｜预紧螺栓总拉力**
	$$
	\normalsize \displaystyle \boxed{F_2=F_0+\frac{C_b}{C_b+C_m}F}
	$$
</callout>
### 情况一：有限寿命计算
条件：本题给定循环次数低于循环基数。
**代入计算**
$$
\normalsize \displaystyle \sigma_{-1N}=350\times100^{1/9}
$$
**计算结果**
$$
\normalsize \displaystyle \sigma_{-1N}\approx583.8\,\mathrm{MPa}
$$
**判断说明**
计算值超过本题给定的屈服上限，因此本题最终取值受该上限限制。
<callout icon="✅" color="green_bg">
	**最终取值**
	$$
	\normalsize \displaystyle \boxed{\sigma_{-1N}=550\,\mathrm{MPa}}
	$$
</callout>
```

独立数学块不自动按手机宽度折行。`aligned` 环境可辅助等号对齐，但其多列总宽度仍需检查；手机默认更偏好短的独立公式块。不要把中文解释塞进 aligned 或同一个超长数学块。排版强调不得改变数学符号含义，也不得为缩短公式随意新增符号或更改计算。

## 4. 验证

回读核对 equation 块、所选字号、单位、完整数学内容、计算后独立段落、绿色结果框。出现过裁切的长式必须做窄宽度检查；本地浏览器模拟通过不等于在用户手机 Notion 界面实测。修复已有笔记时只定点调整字号和分段，保留原有推导、值、图片及人工内容。

依据：[Notion 数学公式](https://www.notion.com/help/math-equations)、[KaTeX 字号与换行行为](https://katex.org/docs/supported.html)。
