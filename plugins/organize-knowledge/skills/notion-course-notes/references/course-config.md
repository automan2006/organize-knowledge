# 配置使用者自己的课程位置

公开版不预设 Notion 页面、数据库、数据源、工作区或个人账号。仅在使用者连接自己的 Notion 并明确指定归档位置后写入。

首次使用先确认：课程页面或课程数据库链接、时区、是否明确要求保存。用户只要求预览时不写入；归档位置缺失时询问，不把搜索结果当作默认授权。

用户提供数据库时 fetch 获取当前 schema 和真实数据源，读取课程标题字段再匹配。提供普通课程页面时在其下创建子页。时区优先采用用户明确设置或宿主可靠上下文，无法确定时询问。保存意图明确后不重复确认同一次归档。

课程命名、数据库字段、学期和学习科目都以该使用者的实际数据为准。机械工程、数学等只能作分类示例，不能自动创建这些课程。找不到课程、多候选、目的地失效或权限不符时让用户指定，不擅自改数据库 schema、移动现有笔记或选择作者的页面。

在当前对话沿用已确认的位置。若用户需要跨对话复用，可让其通过宿主支持的私人设置保存；不要把真实配置提交到本仓库。公开版不要求把 Notion token 写进 Skill 或聊天。

整理标识放在笔记末尾的折叠“归档信息”：插件名称与版本、真实来源定位、主题、归档日期、覆盖状态、图片清单。缺少真实会话 ID 时不伪造；通过来源描述和清单辅助识别重复，不确定时询问。
