# 长文字学术笔记模板

以随包的 [课程笔记布局示意](../assets/note-layout.svg) 为颜色和布局依据。两者都要落实，不能仅用彩色标题替代示意图的分区布局。排版示例中的公式和数值不能移植到其他学科。正文必须是可编辑的 Notion 原生块，保留全部知识解释、推导和例题步骤。

所有科目均遵守 [完整学习档案标准](../../study-chat-notes/references/complete-learning-archive.md)。本模板用于真实课程内按学习日期组织的详细专题；当天总目录负责导航、主题与覆盖信息，不用一页摘要替代专题全文。每个专题保留可访问的原始提问、助手原回答全文、连续追问和纠错，配合完整讲解、逐步计算、知识联系与复习自测。

## 布局

采用原生 `<columns>` / `<column ratio>`，默认桌面和网页版三栏布局。顶部标题区与底部扩展区横跨整页。比例是目标比例，由 Notion 实际渲染决定，不使用 CSS 模拟。

1. **页首**：书本图标、课程笔记标识、章节号及大标题；下方课程、主题关键词、日期、真实来源和覆盖状态。章节号未知则省略，不伪造课程进度。书桌主题等横幅仅在有独立合适图片及支持设置封面的工具时添加，不能把整张模板截图设为封面冒充横幅。
2. **左栏 16%**：浅绿“本页概览”、原生 `<table_of_contents/>`；分隔线后列“相关笔记”。只链接真实页面。它是普通分栏，不承诺像网站侧栏那样固定悬浮。
3. **中栏 52%**：依次为浅蓝“基本概念”、浅蓝“核心原理／制度／方法”、浅绿“分类比较与应用”。每个模块分三级标题，完整说明定义、边界、条件、单位和常见混淆；长推导保留在对应正文，必要时扩展到下方全宽区。
4. **右栏 32%**：浅黄“本节重点”、浅粉“重要公式”、浅蓝“示意图”。重点是学习目标和核心问题，复习清单默认未勾选。公式卡片给公式、符号和适用条件，完整推导在正文可找到。非数学内容改为“核心规则”。图像保留可读尺寸和图注；复杂宽图放正文下方的全宽图解区，右栏保留图名和指向实际位置的引用。
5. **三栏下方两栏 60% / 40%**：左侧浅蓝“例题解析”，右侧浅红“总结与易错点”。例题保留题目条件 → 思路 → 全部计算／代码步骤 → 结果及单位 → 自检 → 可迁移方法；易错点记录错误想法、正确解释及原因，保留用户的实际追问与纠错。
6. **底部全宽**：长推导、长例题的续篇、宽图／宽比较表（需要时）、原始问答链、跨日期知识联系、复习自测与答案位置、待解决问题、参考来源、折叠“归档信息”。续篇必须有明确标题，并从原模块说明续读位置，避免以“详见”丢掉正文。原始问答可紧跟对应知识点；过长时在这里用明确命名的完整区块保留首问、原回答和各次追问，不只列问题标题或最终答案。

手机呈现由 Notion 控制：右栏内容会顺序排到左栏内容下方，不强制 iPhone 显示桌面三栏，也不根据当前发起调用的 ChatGPT 客户端另存一份不同布局。保持标题、原生目录和图注清楚，方便纵向阅读。

核心讲解展开，扩展证明和练习答案可用折叠块。内容超长则先按专题拆成完整子页，每个专题仍沿用本模板；不能为了让左右栏等高而缩减解释、删掉图片、缩小字体或只保留摘要。没有实际内容的模块省略。

## 配色

使用 Notion 原生预设，统一的浅色区块；原生 API 不提供任意十六进制颜色、字体和圆角，不能承诺像素级复刻。

- 本页概览、分类与方法：`green_bg`。
- 基本概念、原理、示意图和例题：`blue_bg`。
- 本节重点、口诀和提示：`yellow_bg` 或`orange_bg`。
- 公式：`pink_bg`。
- 总结与易错点：`red_bg`，有需要时用 `pink_bg` 降低视觉强度。
- 普通正文：默认文字色与页面背景，保留清晰长文可读性。

彩色卡片用带图标的 callout 与带底色标题实现。色彩辅助理解，标题必须保留“公式”“提示”“易错点”等文字。仅在有真实分类比较时用原生表格，不用表格拼装整页布局或装长段落。

## 图片与例题公式的视觉重点

回答中的实物配图、图片网格、图片检索卡片和生成示意图都按 [图片归档流程](images.md) 实际保存，不只留文字描述或图片标题；可取独立原图时按概念配图，只有拼图或截图时如实标明来源和缺图范围。

全部例题按 [手机公式与分步计算排版](formula-presentation.md) 呈现：关键公式放粉色框，根据宽度在稍大、常规、较小字号之间选择，不能一律放大；代入、计算结果、判断说明与最终取值分别成块。最终取值放绿色框，保留单位，字号同样检查。长式先缩到可读范围，仍超宽时转全宽区或拆行，不塞进侧栏；保留完整推导。此要求优先于布局骨架里简写的“实际公式”示例。

## Notion 原生结构示例

涉及可交互函数图表时，按 [HTML 交互归档](interactive-charts.md) 在对应知识点后插入原生 `<embed>`，复杂图放全宽区，保留公式、参数/单位与来源说明。静态预览仅作补充；不要把 HTML 当图片或源码块，也不把适配 Notion 容器说成像素级复刻 ChatGPT 界面。

以下是布局骨架，执行时将示意文字换成完整内容，不把说明或占位词写进最终笔记。真实数学块用 `$$` 包裹 LaTeX，行内数学遵守当前 enhanced Markdown 规范。嵌套块使用制表符缩进。

```text
<columns>
	<column ratio="16">
		<callout icon="📑" color="green_bg">
			**本页概览**
		</callout>
		<table_of_contents/>
		---
		**相关笔记**
		已有相关笔记的真实链接
	</column>
	<column ratio="52">
		## 1. 基本概念 {color="blue_bg"}
		### 1.1 实际概念名称
		完整解释、条件和必要的推导
		## 2. 核心原理与方法 {color="blue_bg"}
		完整方法与操作步骤
		## 3. 分类比较与应用 {color="green_bg"}
		真实分类、比较依据与场景
	</column>
	<column ratio="32">
		<callout icon="⭐" color="yellow_bg">
			**本节重点**
			- [ ] 根据本次知识生成的学习目标
		</callout>
		<callout icon="∑" color="pink_bg">
			**重要公式**
			实际公式、符号和适用条件
		</callout>
		## 🖼️ 示意图 {color="blue_bg"}
		实际已上传的原图及图注
	</column>
</columns>
<columns>
	<column ratio="60">
		## ✍️ 例题解析 {color="blue_bg"}
		题目、完整步骤、答案与自检
	</column>
	<column ratio="40">
		## ⚠️ 总结与易错点 {color="red_bg"}
		实际误区、纠正与解释
	</column>
</columns>
```

保存后回读，核对三栏、两栏、各区颜色、目录、公式和图片块是否存在，再按来源清单逐条核对原问题、原回答、追问链、推导中间步骤、完整例题、图表位置、知识联系和自测解析。检查日期目录、专题父级与真实链接，长文确认末尾和分片连续性；不能只看到标题就说知识完整。若工具无法写入分栏，明确报告布局尚未实现，不悄悄退回单列却宣称与原图一致。工具回读可核对块结构和文本覆盖；没有实际 Notion 界面截图时，说明视觉效果仍待实测。

平台依据：[Notion 分栏与手机显示](https://www.notion.com/help/columns-headings-and-dividers)、[Notion 页面配色与样式](https://www.notion.com/help/customize-and-style-your-content)。
